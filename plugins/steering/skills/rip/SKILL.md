Treat all existing code as disposable, not sacred, and make sure the change is architecturally sound. Be bold in your choices, even if it means undoing existing code and pruning unnecessary complexity to create a cleaner solution. This is not throwaway code: it must be maintainable and designed to be long lived, going beyond accomplishing the immediate task to deliver a solution that will survive ten years.
